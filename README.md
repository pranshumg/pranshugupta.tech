# pranshugupta.tech

Source for my personal portfolio, live at **[pranshugupta.tech](https://pranshugupta.tech)**.

A single static page — plain HTML, CSS and a little JavaScript, no build step — hosted on GitHub Pages.

- Light (cream) and dark themes with an animated switch
- Experience, projects and skills, plus a downloadable [resume](resume.pdf)

## Run locally

```bash
python -m http.server 5173
```

Then open http://localhost:5173.

## Deploy

Push to `main` — GitHub Pages republishes automatically. The custom domain is set in [`CNAME`](CNAME).
